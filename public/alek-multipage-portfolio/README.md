# ALEK.DEV Multi-Page Portfolio

## Pages
- `index.html` — Home
- `services.html` — Services and delivery process
- `projects.html` — Filterable project showcase
- `about.html` — About, credentials and skills
- `contact.html` — Contact details and inquiry form

## Run locally
Open `index.html` in a browser. For best results, use a simple local web server or deploy the folder to static hosting.

## Before publishing
1. Replace the portrait placeholder with your own portrait.
2. Update email address and social profile links.
3. Replace illustrative project images and descriptions with real projects. Do not present concept cards as completed client work.
4. The contact form uses `mailto:` and does not store submissions. Connect a form backend or form service if you need server-side submissions.
5. Check all external image links and use your own licensed images where possible.

The site uses a shared stylesheet and JavaScript file to keep the multi-page design consistent. Google Fonts, Lucide icons, and project preview images are loaded externally.
